# 🌍 About the Project

Waste management has become one of the world's biggest environmental challenges. Many recyclable materials and reusable products are discarded even though they still have value.

**RecycleHub** is designed to solve this problem by providing a digital marketplace where users can easily buy and sell recyclable materials and second-hand products.

The system encourages sustainable living by extending product life cycles, reducing landfill waste, and supporting environmentally friendly purchasing decisions.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/RecycleHub.git
```

Move into the project directory

```bash
cd RecycleHub
```

Initialize the project

```bash
npm init -y
```

Install Electron

```bash
npm install electron --save-dev
```

---

# ▶️ Running the Application

Make sure your **package.json** contains:

```json
"scripts": {
  "start": "electron ."
}
```

Run the project:

```bash
npm start
```
